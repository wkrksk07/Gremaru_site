# Gremaru (그리마루) — 사이트 & 릴리스

GitHub Pages 사이트(`gremaru.lysc.kr`)와 릴리스 다운로드를 위한 공개 저장소입니다. 소스 코드는 별도의 비공개 저장소에 있습니다.

- 페이지: `index.html`, `support/`, `privacy/`, `licenses/` (앱은 `/` 와 `/support/` 로 링크, Play Console 개인정보처리방침 URL은 `/privacy/`)
- 릴리스: 서명된 APK와 `SHA256SUMS.txt` 를 Releases에 첨부
- Based on PhotoCraft by the ArtCraft team. Gremaru는 독립 프로젝트이며 ArtCraft 팀과 무관합니다.
